# Фронтенд для Трекера привычек

Простая SPA (Single Page Application) для работы с API трекера полезных привычек.

## Особенности

- 🎨 Современный дизайн с градиентами и анимациями
- 📱 Адаптивная верстка для всех устройств
- 🔐 Полная интеграция с API (регистрация, авторизация, CRUD)
- 📊 Статистика по привычкам
- 🌍 Просмотр публичных привычек
- ⚡ Быстрая работа без дополнительных зависимостей
- 🎯 Интуитивный интерфейс

## Технологии

- **HTML5** - семантическая разметка
- **CSS3** - современные стили с CSS Grid и Flexbox
- **JavaScript (ES6+)** - нативный JS без фреймворков
- **Bootstrap 5** - компоненты и сетка
- **Font Awesome** - иконки

## Запуск

### Вариант 1: Простой HTTP сервер

```bash
# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080

# Node.js (если установлен)
npx http-server -p 8080
```

### Вариант 2: Live Server (VS Code)

1. Установите расширение "Live Server" в VS Code
2. Откройте `index.html`
3. Нажмите "Go Live" в статусной строке

### Вариант 3: Открыть напрямую

Просто откройте `index.html` в браузере (может не работать из-за CORS)

## Настройка

В файле `app.js` измените `API_BASE_URL` если ваш бэкенд запущен на другом порту:

```javascript

```

## API интеграция

Приложение полностью интегрировано с Django REST API:

### Эндпоинты
- `POST /api/users/register/` - регистрация
- `POST /api/users/login/` - авторизация
- `GET/PATCH /api/users/profile/` - профиль
- `GET/POST /api/habits/` - привычки пользователя
- `GET/PATCH/DELETE /api/habits/{id}/` - конкретная привычка
- `GET /api/habits/pleasant_habits/` - приятные привычки
- `GET /api/public-habits/` - публичные привычки

### Аутентификация
Используется Token-based аутентификация:
```javascript
headers: {
    'Authorization': `Token ${authToken}`
}
```

### Обработка ошибок
- Автоматическое отображение ошибок API
- Валидация на стороне клиента
- Graceful fallback для сетевых ошибок
