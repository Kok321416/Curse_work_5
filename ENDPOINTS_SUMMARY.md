# 🚀 Сводка по API эндпоинтам

## ✅ Реализованные эндпоинты

### 👤 **Пользователи (Users)**
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| `POST` | `/api/users/register/` | Регистрация | Публичный |
| `POST` | `/api/users/login/` | Авторизация | Публичный |
| `GET` | `/api/users/profile/` | Просмотр профиля | Авторизованные |
| `PATCH` | `/api/users/profile/` | Обновление профиля | Авторизованные |

### 🎯 **Привычки пользователя (Habits)**
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| `GET` | `/api/habits/` | Список привычек + пагинация | Владелец |
| `POST` | `/api/habits/` | Создание привычки | Авторизованные |
| `GET` | `/api/habits/{id}/` | Детали привычки | Владелец |
| `PATCH` | `/api/habits/{id}/` | Обновление привычки | Владелец |
| `DELETE` | `/api/habits/{id}/` | Удаление привычки | Владелец |
| `GET` | `/api/habits/pleasant_habits/` | Приятные привычки для связывания | Владелец |

### 🌍 **Публичные привычки (Public Habits)**
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| `GET` | `/api/public-habits/` | Список публичных привычек + пагинация | Авторизованные |
| `GET` | `/api/public-habits/{id}/` | Детали публичной привычки | Авторизованные |

### 📚 **Документация**
| Метод | URL | Описание | Доступ |
|-------|-----|----------|--------|
| `GET` | `/api/schema/` | OpenAPI схема | Публичный |
| `GET` | `/api/docs/` | Swagger UI | Публичный |
| `GET` | `/api/redoc/` | ReDoc документация | Публичный |

## 🔧 **Технические особенности**

### **Аутентификация**
- ✅ Token-based аутентификация
- ✅ Автоматическое создание токенов при регистрации/авторизации
- ✅ Заголовок: `Authorization: Token <token>`

### **Пагинация**
- ✅ Размер страницы: 5 элементов
- ✅ Параметр: `?page=N`
- ✅ Ответ: `{count, next, previous, results}`

### **Фильтрация**
- ✅ По типу привычки: `?is_pleasant=true/false`
- ✅ По публичности: `?is_public=true/false`
- ✅ По пользователю (для публичных): `?user=<user_id>`

### **CORS**
- ✅ Настроен для фронтенда
- ✅ Поддерживаемые порты: 3000, 8080, 5500
- ✅ Поддержка credentials

### **Валидация**
- ✅ Время выполнения ≤ 120 секунд
- ✅ Периодичность 1-7 дней
- ✅ Взаимоисключающие поля (reward/related_habit)
- ✅ Логика приятных привычек

### **JavaScript API вызовы:**
```javascript
// Все эти вызовы работают с нашими эндпоинтами:

await apiRequest('/users/register/', { method: 'POST', body: JSON.stringify(data) });
await apiRequest('/users/profile/', { method: 'PATCH', body: JSON.stringify(data) });
await apiRequest('/habits/', { method: 'GET' });
await apiRequest('/habits/', { method: 'POST', body: JSON.stringify(data) });
await apiRequest('/habits/pleasant_habits/', { method: 'GET' });
await apiRequest('/public-habits/', { method: 'GET' });
await apiRequest(`/habits/${id}/`, { method: 'DELETE' });
```
